# Ayush Kumar - Portfolio

Modern premium developer portfolio for Ayush Kumar with an AI-integrated full stack focus.

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP (optional)

## Getting Started

Install dependencies:

```
npm install
```

Run the development server:

```
npm run dev
```

Build for production:

```
npm run build
```

Preview production build:

```
npm run preview
```

## Notes
- Replace social links and email in the Hero and Contact sections with real URLs.
- Add your real resume file at `public/resume.pdf` to enable the Resume button.
